CSV format

The first row must be a header naming the columns (order doesn't matter). Only title is required; all other columns are optional. Dates use YYYY-MM-DD.

ColumnRequiredMeaning
titleyesTask name (up to 255 characters)
notesnoFree-text details
donenotrue/false — mark the task as completed
due_datenoA single date, e.g. 2026-03-03
work_datesnoComma-separated dates or inclusive ranges, e.g. 2026-03-01,2026-03-03-2026-03-05
projectnoName of one of your existing projects
parentnoTitle of another task (from this file or already in the app) to nest under

Example:

title,due_date,work_dates,project,parent
"Plan holiday",2026-07-01,,Personal,
"Book flights",2026-07-10,2026-07-02,Personal,Plan holiday
"Renew passport",,2026-03-01-2026-03-03,Personal,Plan holiday

Rows with problems (bad dates, unknown projects or parents) are skipped and reported; everything else is imported. Duplicate titles are allowed — parent links use the first matching row that isn't the task itself.
